# Screenshots

Drop real screenshots here with these exact filenames - the main `README.md`
already references them, so a file landing here is all it takes, no markdown
editing needed.

| Filename | What to capture |
|---|---|
| `panel-overview.png` | The DockPane open on a real project - Analyze tab, a few sections expanded, ideally with a raster loaded in the map behind it. |
| `tree-detection-result.png` | A Tree Detection result (green/red points) over its source orthophoto, zoomed in enough to see individual crowns. |
| `land-clearing-result.png` | A Land Clearing Detection result (the orange-brown fill polygons) over its source orthophoto. |
| `road-extraction-result.png` | A Road/Trail Extraction result (yellow centerlines) over its source orthophoto, ideally showing a fork or junction. |
| `color-sampler.png` | The Color Reference Sampler panel mid-session (category locked, a few sample points visible in the Contents pane or map). |

PNG preferred (crisp UI text); keep each under a few MB - GitHub renders large
images fine but they're slow to load in a README. Crop out anything
client-confidential (site names, coordinates you don't want public) before
committing, since this is a public repo.
